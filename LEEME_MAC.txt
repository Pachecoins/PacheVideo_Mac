PacheVideo - Guia para macOS
============================

Esta carpeta ya esta preparada para generar PacheVideo.app en macOS.
El .exe de Windows no sirve en Mac: en Mac hay que compilar una app nativa.

Instalacion directa desde GitHub
--------------------------------
Para pasarselo a otra persona, dale este comando:

  bash -c "$(curl -fsSL https://raw.githubusercontent.com/Pachecoins/PacheVideo_Mac/main/install_mac.sh)"

Ese comando baja el repo, compila la app, la instala en:

  ~/Applications/PacheVideo.app

y la abre automaticamente.

Requisitos
----------
1. macOS con Python 3.11+:
   brew install python

   Nota: el Python incluido por Apple puede ser 3.9 y no alcanza para
   yt-dlp actual. El instalador install_mac.sh intenta usar python3.12,
   python3.11 o python3.10, y si no encuentra ninguno intenta instalar
   Python moderno con Homebrew.
   Las dependencias se instalan dentro de .venv-macos para no tocar el
   Python global de Homebrew.

2. Xcode Command Line Tools:
   xcode-select --install

3. FFmpeg, recomendado:
   brew install ffmpeg

Probar sin instalar
-------------------
Desde Terminal, dentro de esta carpeta:

  python3 -m pip install -r requirements.txt
  python3 pache_video.py

Generar PacheVideo.app
----------------------
Desde Terminal:

  cd "/ruta/a/esta/carpeta"
  bash build.sh

Resultado:

  dist/PacheVideo.app

Abrir la app:

  open dist/PacheVideo.app

Generar instalador .pkg
-----------------------
Despues de generar la app:

  bash create_pkg.sh

Resultado:

  installer_output/PacheVideo_macOS_v1.0.0.pkg

Primera apertura y Gatekeeper
-----------------------------
Si macOS muestra que la app viene de un desarrollador no identificado:

  Clic derecho sobre PacheVideo.app > Abrir > Abrir

Para distribucion masiva conviene firmar y notarizar con Apple Developer ID.
El script create_pkg.sh deja al final el ejemplo de productsign.

Notas de compatibilidad
-----------------------
- El logo se toma desde logo.png.
- build.sh genera icon.icns automaticamente desde logo.png si no existe.
- ffmpeg se incluye dentro de la app.
- Las notificaciones usan osascript en macOS.
- El boton de actualizar usa Terminal en macOS y PowerShell en Windows.
- Las descargas se guardan en ~/.pachevideo/downloads.json.
- Si importas cookies.txt, se copia a ~/.pachevideo/cookies.txt.
  Ese archivo es privado: no se sube a GitHub ni se mete en instaladores.
